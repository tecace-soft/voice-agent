고객 여정: 데모에서 실제 전화 응대까지

이 제품이 무엇인지, 구성 요소가 어떻게 연결되는지, 어떤 기능이 있는지, 그리고 업체가 첫 데모부터 실제 전화를 받는 어시스턴트까지 어떻게 가는지 정리했습니다. 프로젝트를 처음 보는 사람도 따라올 수 있게 썼습니다.

1분 요약 시스템 구조 전체 기능 고객 여정 두 개의 게이트 실제 통화 어디서 되는지 남은 일 용어집

1분 요약

Voice Agent는 소규모 업체를 위한 AI 전화 응대원입니다. 손님이 업체에 전화했는데 아무도 받지 않으면(업체가 원하면 모든 전화를) 우리 어시스턴트가 받습니다. 자연스러운 목소리로 말하고, 업체 정보를 알고 있으며, 사장님이 설정한 대로 통화를 처리합니다.

  • 질문에 답변영업시간, 가격, 서비스, 위치, FAQ를 업체 프로필에서 찾아 답합니다.
  • 예약 잡기빈 시간을 확인하고 업체 캘린더에 직접 예약을 넣습니다.
  • 담당자 연결사람이 필요한 전화는 맞는 담당자에게 돌려줍니다.
  • 메시지 받기이름, 회신 번호, 용건을 대시보드와 Google Sheet에 남깁니다.
  • 링크 문자 보내기예약 페이지나 메뉴를 문자로 보냅니다. 데모에서만 되고 실제 전화는 아직입니다.

업체 (고객)

전화번호의 주인입니다. 데모를 써 보고, 대시보드에서 어시스턴트를 설정해 퍼블리시하고, 자기 번호를 우리 번호로 포워딩합니다. 이후 통화와 메시지를 확인합니다.

TecAce 어드민

업체를 찾아 데모를 만들고, 셋업을 승인하고, 전화번호를 배정하고, 회선을 켭니다(Go live). 사용량을 지켜봅니다.

발신자

업체의 손님들입니다. 우리 제품을 볼 일은 없고, 평소처럼 업체에 전화해서 어시스턴트와 대화합니다.

시스템 구조 한눈에 보기

모든 데이터는 백엔드 하나에 있습니다. 전화 에이전트, 대시보드, 공개 페이지, 음성사서함 워커가 모두 이 백엔드와 통신합니다. 각 상자는 레포 안의 독립된 앱이고 각자 README가 있습니다.

두 개의 게이트

업체는 어드민이 행동해야만 다음 단계로 갑니다. 결제와 Twilio 번호 구매는 지금은 앱 밖에서 처리합니다.

데모온보딩라이브
고객이 설정 수정불가, 읽기 전용가능가능
테스트 통화공개 데모 페이지만앱에서 가능초안 사용, 월 30분앱에서 가능
통화 설정 퍼블리시불가 (403)가능가능
실제 전화 응답안 함안 함not_live_stage가능
다음 단계 조건어드민이 셋업 요청을 승인체크리스트 통과 후 어드민이 Go live 클릭—

Go live 체크리스트

  • 업체 정보 완료 (이름 + 정보)
  • 통화 설정 퍼블리시됨
  • 전화번호 배정됨
  • 퍼블리시된 설정이 그 번호와 일치
  • 업체 연락처 또는 연결 번호 (경고만, 필수 아님)

어드민이 하는 일 (순서대로)

  1. 업체 추가(리서치는 선택)하고 CRM 단계 관리
  2. /c/<id> 데모 링크 보내기
  3. 셋업 요청 승인 또는 거절
  4. Agent numbers 화면에서 Twilio 번호 배정
  5. 체크리스트 확인 후 Go live 클릭
  6. 통화 시간 확인, 피드백 답변

실제 통화에서 일어나는 일

업체가 번호를 포워딩하면 모든 전화가 전화 에이전트를 거칩니다. 에이전트는 전화를 받을 때 퍼블리시된 설정을 읽고, 통화 중에 도구를 호출하고, 끊으면 통화를 기록합니다.

기능별로 어디서 되는지

같은 설정이 세 종류의 통화에 쓰입니다. 새 기능은 앱 테스트 통화와 공개 데모에 먼저 들어가고, 실제 전화는 phase 3에서 따라잡습니다.

용어집

데모 고객 (Demo customer)
우리가 데모를 만든 업체. GLHF-0009 같은 영구 ID를 받습니다.
단계 (Phase)
데모 → 온보딩 → 라이브. users.status에 demo, pre-production, production으로 저장.
초안과 퍼블리시 (Draft / Published)
설정 수정은 초안입니다. 테스트 통화는 초안을, 실제 전화는 퍼블리시된 것만 씁니다.
통화 설정 (Call settings)
메시지, 전화 연결, 링크, 예약 규칙. 설정 스튜디오의 Calls 그룹입니다.
조합된 세션 (Composed session)
설정으로 한 통화용 프롬프트와 도구를 만든 것. 지금은 앱과 데모 통화에서 씁니다.
룰북 (Rule book)
전화 에이전트의 자체 Python 프롬프트. phase 3에서 조합된 세션으로 바꾸기 전까지 실제 통화가 씁니다.
에이전트 번호 (Agent number)
업체에 배정된 Twilio 번호. 발신자가 직접 거는 번호는 아닙니다.
착신 전환 (Call forwarding)
업체가 자기 번호를 에이전트 번호로 돌려 둡니다. 부재중만 또는 모든 전화.
리서치 (Research)
OpenAI 웹 검색으로 데모의 프로필, FAQ, 영업시간, 프롬프트를 채우는 작업.
준비 체크리스트 (Readiness)
Go live 전에 필요한 조건: 업체 정보, 퍼블리시된 설정, 번호, 둘의 일치.
스테이징 (Staging)
테스트용 별도 환경(va-staging-backend, Neon 브랜치). 운영 배포는 master에서만.
