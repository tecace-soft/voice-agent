Admin 화면 재설계 목업

tecace-voice-agent-dashboard의 admin 화면 전체를 다시 정리한 정적 목업입니다. Demo(Prospect) 쪽을 가장 깊게 다뤘습니다. 각 페이지 오른쪽 아래의 검은 패널이 변경 메모이고, 화면의 주황 번호와 짝을 이룹니다. 데이터는 전부 가짜이며 백엔드와 연결되어 있지 않습니다.

정리 원칙

  1. 같은 동작은 한 곳에만. 지금은 리서치 재실행 3곳, 데모 시간 추가 3곳, 데모 페이지 열기 5곳, 저장 방식 4가지입니다. 목업에서는 동작마다 자리를 하나로 정했습니다. (Taste Skill: No duplicate CTA intent)
  2. 동작은 그 데이터 옆에. 링크 스위치·시간은 링크 카드에, 승인·거절은 요청 내용 옆에, Go live는 체크리스트 아래에 둡니다.
  3. 저장 규칙 한 줄. 입력하는 대로 저장하고, 실제 손님에게 나가는 통화 설정만 Publish로 게시합니다. 데모는 실제 회선이 없어 바로 저장합니다.
  4. 무엇을 해야 하는지 먼저. 목록의 'Needs you' 탭과 'Next step' 열, 상세 페이지의 단계 표시(stepper)와 다음 단계 카드.
  5. 브랜드 규칙은 유지. #116DFF 하나, Pretendard, 본문 500, 16px 외곽선 카드, sentence case(대문자 그룹 라벨 제거), em-dash 없음. 한 가지만 제안으로 바꿨습니다: 보조 글씨 색을 더 진하게 해서 대비 4.5:1을 넘깁니다(지금 약 3.7:1).

확인이 필요한 것

  1. 사이드바 재편은 라우트(`#/demos/...`, `#/accounts`)와 회귀 스크립트에 영향이 큽니다. 이름만 바꾸고 URL은 유지하는 단계적 방법도 있습니다.
  2. Demo analytics의 퍼널, Prospects의 'Needs you' 탭은 지금 데이터로 계산 가능해 보이지만 백엔드 확인이 필요합니다.
  3. 데모의 Receptionist 탭 자동 저장은 지금 '한 번에 PATCH' 구조와 다릅니다. 필드 단위 저장 API가 필요할 수 있습니다.
  4. Taste Skill은 원래 대시보드용이 아니라서, 정리 원칙만 가져오고 시각 규칙은 TecAce 브랜드를 따랐습니다.
