고객 화면에서 바뀐 것

  1. 단계마다 다른 Home. 데모는 '전화해 보기 + Request setup', 온보딩은 체크리스트, 라이브는 회선 상태와 오늘의 메시지. 지금은 데모 고객은 영업 지표(Link opens, People)를 보고, 온보딩 고객은 로그인 즉시 설정 폼 위에 알림 띠 3개를 봅니다.
  2. 사이드바 3~4개. Home, Calls, Receptionist, Phone line. 지금은 음성 에이전트 고객에게도 Voicemail 4개 항목이 보이고, 브랜드가 'TecAce Transcribe', 꼬리말이 'Last run'입니다.
  3. 고객 말로. '게시된 설정이 그 번호와 동작', '모든 에이전트 통화', Happy/Mixed 기분 라벨, 'from Accounts' 같은 운영 문구를 뺐습니다.
  4. 고객이 할 수 없는 일은 '우리가 합니다'로. 번호 배정과 Go live는 관리자 몫이라 체크리스트에서 점선 단계로 구분합니다.
  5. 죽은 컨트롤 제거. 데모 계정에서는 아무 일도 안 하는 상단 'Refresh', 항상 'No runs yet'인 'Last run', 'Showing <이름>' 블록, '실행(run)'을 언급하는 피드백 힌트처럼 음성사서함 앱에서 온 것들을 고객 화면에서 뺍니다.
  6. 새 제안 3개: 메시지 '처리 완료' 표시, 통화별 '잘 됐다/아니다' 피드백, 회선 일시 중지. 모두 백엔드가 필요합니다.

Admin과 고객 화면의 관계

같은 데이터고객에게관리자에게
설정 스튜디오Receptionist (7개 메뉴, 고객 말)Prospect › Receptionist, Business settings (전체 섹션)
통화 기록Calls (결과별 필터)Transcripts (모든 업체), Prospect › Calls (리뷰·테스트 표시)
고칠 점Worth a look (고치는 링크)What to fix (FAQ 추가, 시간 편집)
회선Phone line (전환 안내, 요금)Customers 서랍 (번호 배정, Go live), Phone numbers
셋업 진행Home 체크리스트 (내 일 / 우리 일)Prospect stepper, Customers의 Go live 진행률
같은 컴포넌트를 두 역할이 공유하되, 메뉴·문구·동작 범위만 다르게 가는 방향입니다.

확인이 필요한 것

  1. 고객 사이드바에서 Voicemail을 빼도 되는지. transcribe 앱(음성사서함) 고객과 음성 에이전트 고객이 같은 계정 체계를 쓴다면, 메일함이 있는 계정에만 보이게 하는 조건이 필요합니다.
  2. '받은 전화 / 예약 / 메시지 / 연결' 네 지표는 통화 결과(outcome) 데이터로 계산할 수 있어 보이지만 확인이 필요합니다.
  3. 데모 단계 고객의 Receptionist 미리보기를 요약 카드로 줄이는 것이 영업상 맞는지(지금은 전체 설정을 읽기 전용으로 보여 줌).
  4. Admin 쪽 확인 사항은 Admin 목차에 있습니다.
