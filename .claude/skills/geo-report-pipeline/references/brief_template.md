# Interview brief template (write to brief.md, confirm at Gate 1)

Fill this from Phase 1 research + the interview, then present it for approval.

```
# GEO 파이프라인 브리핑 — <Target> (<YYYY-MM>)

Target: <name> — <one-line: what it is, location, who it serves>
URL: <url>

## 시장 이해 (리서치 요약)
<one paragraph: what the target sells, business type (enterprise vs local SMB),
the real competitor rings, region, and — for local SMBs — location.>

## 인터뷰 결정사항
- 경쟁 링(측정 대상): <which competitor pools>
- 우선 고객 세그먼트: <segments to weight>
- 지역 범위: <geography>
- 분석 목표: <visibility benchmark / gap-finding / high-value growth / sentiment>
- 언어: <question language>  (근거: <target market>)
- 질문 수: <N>   ← 반드시 사용자에게 확인
- 경쟁사/키워드/페르소나 오버라이드(있으면): <...>

## 카테고리·페르소나 축(초안)
- 카테고리: <list>
- 페르소나: <list>

## 유의점
<any caveats — e.g. positioning inferred from directories, site not fetchable, etc.>
```

Keep the category and persona sets internally consistent across the questions in this
run, so per-category and per-persona numbers mean something.

Whether this run is a standalone snapshot or one point in a trend line is the user's
call and varies by engagement — ask, don't assume. Only when they say they want a
comparable run should you carry the previous run's categories and personas forward
unchanged; otherwise pick the axes that fit this target today.
